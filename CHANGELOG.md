# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии —
[SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-04

### Добавлено

- Каталог: дерево категорий, карточки товаров, скидки, фильтры, полнотекстовый поиск
  с русской морфологией и подсказками при опечатках.
- Отзывы с оценкой и модерацией, рейтинг товаров, галерея изображений.
- Корзина гостя и покупателя с объединением при входе.
- Оформление заказа: транзакционное списание остатков, промокоды, самовывоз,
  курьерская доставка и письма покупателю.
- Личный кабинет: история заказов и отмена нового заказа с возвратом остатков.
- Панель менеджера: допустимые переходы статусов, история изменений,
  группа «Менеджеры магазина» с ограниченными правами.
- Регистрация, собственная модель пользователя, учёт сотрудников и отделов.
- REST API каталога, корзины, заказов и сотрудников; аутентификация JWT и проверка прав.
- Docker: окружение разработки и отдельный прод-подобный стенд с многоэтапным
  образом, Gunicorn, nginx, HTTPS, раздачей static/media и отдельными миграциями.
- Проверка приложения и базы на `/healthz/` с номером версии, автоматические
  тесты и повторяемый сценарий проверки покупки по HTTPS.
