## Особенности контрольной точки

- В части 4 методичка уже ссылается на admin-маршрут заказа, но регистрирует его только в части 5. Поэтому в `templates/base.html` маршрут разрешается через `{% url ... as manager_url %}`; ссылка скрыта до регистрации панели. Иначе суперпользователь получает `NoReverseMatch` на всех страницах магазина. После реализации части 5 ссылка появится без дополнительных правок.
- Промокоды регистрируются в admin только в части 5, поэтому учебный `STUDENT10` создан напрямую в новой БД: скидка 10%, лимит 2, действует со дня перед восстановлением ещё 90 дней, счётчик 0.
- Проверка адреса курьера в сервисе намеренно ещё не добавлена: до части 6 адрес проверяется HTML-формой и ограничением БД, как в методичке. Прямой вызов сервиса с курьером без адреса выдаёт `IntegrityError`.
- Отмена заказа не уменьшает `used_count` промокода — это правило кода методички. Собственное обоснование этого бизнес-правила для отчёта ещё нужно сформулировать.
- Веб-интерфейс Mailpit опубликован только на `127.0.0.1:8025`, SMTP наружу не открыт.
- Это учебный dev-стенд, не production; до части 6 API сотрудников остаётся открытым, как в исходном проекте. Не публикуйте стенд в интернет.

Старая БД, `.env`, пароли, корзины, заказы, сотрудники и загруженные файлы с другого ПК недоступны и не восстановлены.

Создан новый суперпользователь `admin`. Его случайный пароль записан **вне Git-репозитория**: `../corporate_is-local-access.txt`. Не публикуйте этот файл и `.env`.

Проверочные пользователи и заказы откатились транзакцией: база оставлена без заказов, остатки исходные, STUDENT10 не использован. Последовательности PostgreSQL при откате не возвращаются: первые реальные номера могут начинаться не с 1.
В Mailpit оставлено одно явно помеченное проверочное письмо. Это не письмо со старого ПК.

## Команды PowerShell

Из корня `corporate_is`:

```powershell
docker compose up -d --build
docker compose ps
docker compose exec web python manage.py migrate
docker compose exec web python manage.py test
```

- Магазин: http://localhost:8000/
- Админка: http://localhost:8000/admin/
- Ловушка писем: http://localhost:8025/

Не запускайте `seed_catalog` после собственных покупок без необходимости: команда сбрасывает цены/остатки демонстрационных товаров.
`docker compose down` сохраняет данные. **Не используйте `docker compose down -v`**, если данные нужны.
Имя Compose-проекта сохранено: `corporate-is-lab1`.

Git на этом ПК установлен в пользовательскую папку `%LOCALAPPDATA%/Programs/MinGit`; её `cmd` добавлена в пользовательский PATH. Для команды `git` может понадобиться открыть новый терминал/перезапустить IDE. Git Bash в этой минимальной поставке отсутствует; используйте PowerShell.
