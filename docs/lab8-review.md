# Лабораторная № 8. Ревью компонента ProductList

| Проблема в исходном примере | Последствие для магазина |
| --- | --- |
| Импорт из `react-router-dom` | Пакета нет в зависимостях, сборка завершится ошибкой. |
| Параметры компонента имеют тип `any` | Компилятор пропустит категорию неверного типа. |
| Запрос выполняется в `useEffect` | Компонент обходит общий кэш и повторно запрашивает уже загруженную категорию. |
| Адрес Django указан напрямую | Браузер обходит прокси Vite. На стенде localhost указывает на компьютер посетителя. |
| Категория вставляется в URL без кодирования | Символ `&` превратит часть значения в отдельный параметр. |
| Код ответа игнорируется | JSON с описанием ошибки попадёт в состояние как список товаров. |
| Используется весь ответ вместо `results` | API возвращает объект страницы, поэтому вызовы `map` и `reduce` завершатся ошибкой. |
| Эффект имеет пустой список зависимостей | После смены категории пользователь увидит старые товары. |
| Запрос нельзя отменить | После исправления зависимостей медленный ответ старой категории сможет перезаписать свежий. |
| У загрузки и ошибки отсутствуют отдельные состояния | Пользователь увидит пустой список и ложный нулевой итог, пока API отвечает или недоступен. |
| Цена складывается как число | Django передаёт цену строкой, поэтому оператор `+` склеит значения. |
| Итог вычисляется по текущей странице | Остальные товары категории не войдут в сумму. |
| Индекс используется как React-ключ | При изменении порядка состояние строки может перейти к другому товару. |
| Ссылка использует ID вместо slug | Маршрут товара по ID вернёт 404. |
| Итог размечен элементом списка товаров | Скринридер посчитает итог ещё одним товаром. |

[Исправленный компонент](../frontend/src/components/ProductList.tsx) использует общий запрос
TanStack Query, отображает текущую страницу и читает сумму всех подходящих товаров из поля `total`.
Сумму вычисляет PostgreSQL по ценам базовых товаров, включая подкатегории. Тест с MSW проверяет,
что сумма приходит с сервера и отображается с копейками.
