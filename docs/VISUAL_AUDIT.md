# Визуальный аудит «Книжной полки»

Исходный коммит — `8aa637e26e7a5324a2ea3ecdd67ed2be8a9b0d4d` ветки `codex/lab11-manager`. На момент начала он совпадал с вершиной ветки на GitHub и включал результаты ревью корректности. Ветка аудита — `codex/visual-audit`.

## Покрытие

Chromium через Playwright, сборка React за nginx, Django и PostgreSQL в отдельном проекте Compose `shop-visual-audit`. Для штатных E2E использовался второй проект с чистой базой. В матрицу вошли гость, покупатель с данными, покупатель с пустыми списками и сотрудник. Изолированная база позволила проверить длинные названия, фамилию, email и адрес, книгу без обложки, 28 заказов и 18 промокодов.

## Контраст и ограничения

Расчёт по основным сплошным цветам палитры дал минимум 5,85:1 в светлой и 7,26:1 в тёмной теме для текста, вторичного текста, ссылок, кнопок и сообщений об ошибке и успехе на предусмотренных фонах. Это проверка выбранных цветовых пар. Полный аудит WCAG, скринридеры, Firefox и WebKit в эту матрицу не входили.

Реестр относится к React Router. Django-сравнение и адресная книга покрыты штатным HTTPS E2E отдельно от визуальных снимков. Состояние «Книга сохранена» в матрице открывалось по URL после сохранения, а реальное сохранение выполняется в штатном E2E.

| --- | --- |
| TypeScript, Oxlint, сборка React | Успешно на итоговых изменениях |
| Vitest | 62 из 62 в 17 файлах на итоговых изменениях |
| Playwright HTTPS | 18 из 18 после основного этапа, затем 6 из 6 затронутых E2E после адаптации истории и состава заказов |
| Матрица Chromium | 282 итоговых PNG. Один тайм-аут при сохранении снимка главной в тёмной теме на планшете закрыт одиночным повтором. Ещё 30 сочетаний для заказов пересняты после точечной доработки. |
| Горизонтальное переполнение и консоль | Переполнения документа в контрольных сценариях не обнаружено. В промокодах на 768 px стрелками прокручено 173 из 173 px внутри таблицы. Записи консоли соответствовали ожидаемым 401, 404, 409 и 503 в негативных сценариях. |
| Клавиатурный фокус | Escape вернул фокус в диалогах жанра, удаления и смены статуса во всех шести профилях. Tab открыл ссылку «К содержимому». |

Все восемь зарегистрированных дефектов исправлены и перепроверены. На контрольных снимках в плотных таблицах заказов и каталога сотрудника при 768 px по-прежнему виден перенос больших сумм и длинных статусов. Текст и действия остаются доступны. Отдельную перестройку этих таблиц в этом проходе не выполняли. Для интерактивных состояний проверялись сценарии из реестра и штатного E2E. Проверка наведения, нажатия и всех комбинаций состояний каждого контрола отдельно не проводилась.

PNG, контактные листы JPG, матрицы JSON и журналы тестов находятся в локальном каталоге `backups/visual-audit/` вне Git. `targeted.json` содержит повтор главной и проверку клавиатурной прокрутки, `orders-followup.json` — результаты точечного прогона заказов.
