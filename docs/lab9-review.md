# Лабораторная №9. Ревью хука корзины

| Проблема в предложенном хуке | Исправление |
| --- | --- |
| В адресе PATCH нет завершающего слеша. Django может отклонить запрос с телом при попытке добавить слеш. | Используем путь `/api/cart/items/{product_id}/` из OpenAPI. |
| Прямой `fetch` обходит типизированный клиент и обновление JWT. | Вызываем `api.PATCH` с типизированными параметрами и телом. |
| Токен берётся из `localStorage.token`, хотя приложение использует другой ключ. | Заголовок авторизации подставляет общий клиент. |
| `response.json()` воспринимает ответ HTTP 400 как успешную мутацию. | `requireData` проверяет ответ и передаёт ошибку API в TanStack Query. |
| Текущий запрос корзины может перезаписать оптимистичное значение. | В `onMutate` сначала отменяем запросы по ключу корзины. |
| Запись в `.quantity` меняет объект кэша на месте и портит снимок для отката. | Создаём новый массив и новую изменённую строку. |
| `find(...).quantity` падает, если строки или кэша ещё нет. | Обрабатываем отсутствие кэша и проверяем индекс строки перед обновлением. |
| Поиск только по товару может изменить другой вариант этого товара. | Сопоставляем товар и вариант, передаём вариант в параметрах PATCH. |
| При нулевом количестве остаётся строка, суммы и счётчик устаревают. | Сразу удаляем строку из кэша и пересчитываем счётчик и суммы. |
| При отказе сервера оптимистичное изменение остаётся на экране. | Сохраняем предыдущую корзину и откатываем снимок, если его ещё не сменило более новое обновление. |
| `invalidateQueries(['cart'])` использует старую сигнатуру, а вызов только в `onSuccess` пропускает ошибки. | По завершении очереди запросов обновляем корзину через `invalidateQueries({ queryKey })`, в том числе после ошибок. |
| `any` скрывает несовпадения формата запроса и кэша. | Типы запроса и корзины берём из схемы API. |

Исправленный код используется в [useCart.ts](../frontend/src/cart/useCart.ts).
Запросы на изменение корзины выполняются последовательно в пределах одной сессии.
Остатки и итоговые суммы сверяются с ответом сервера.
